# Flowy Todo 应用

本项目由 Trae 自动生成，是一个美观、高效的待办事项管理应用，帮助你有条理地规划每一天。

## 已实现功能

### 任务管理

- 📝 **添加新任务**：快速添加带有分类和时间戳的待办事项
- ✅ **标记完成**：通过复选框轻松标记任务完成状态
- ✏️ **编辑任务**：随时修改任务内容和分类
- 🗑️ **删除任务**：带确认提示的安全删除功能

### 任务组织

- 📂 **任务分类**：支持个人、工作、健康三个分类
- 🔍 **任务过滤**：按全部、进行中、已完成过滤任务
- ⏰ **时间排序**：支持按时间正序或倒序排列任务
- 📊 **统计信息**：实时显示任务总数、进行中和已完成数量

### 数据管理

- 💾 **本地存储**：自动保存任务到本地，刷新页面不丢失
- 📤 **导出数据**：将任务导出为JSON文件
- 📥 **导入数据**：从JSON文件导入任务
- 🎯 **导入样例**：快速导入样例数据体验应用功能

## 技术特点

- **响应式设计**：适配不同设备屏幕
- **流畅动画**：提供平滑的用户交互体验

## 技术架构

### 前端技术栈

- **React 19**：用于构建用户界面的JavaScript库
- **Vite**：现代化的前端构建工具，提供快速的开发体验和高效的构建
- **CSS3**：用于样式设计，实现响应式布局和动画效果

### 数据管理

- **localStorage**：浏览器本地存储，用于持久化保存任务数据
- **JSON**：用于数据的序列化和反序列化，支持数据的导入导出

### 应用结构

- **单页面应用**：整个应用在一个HTML页面中运行
- **组件化设计**：采用React组件化思想，代码结构清晰
- **模块化开发**：功能模块分离，便于维护和扩展

### 核心模块

- **任务管理模块**：处理任务的增删改查操作
- **数据存储模块**：负责数据的本地存储和读写
- **UI渲染模块**：负责用户界面的渲染和交互
- **数据导入导出模块**：处理任务数据的导入导出功能

## 如何使用

1. **本地使用**：直接在浏览器中打开 `index.html` 文件
2. **服务器部署**：将本目录中的所有文件上传到你的web服务器

### 使用指南

1. **添加任务**：在输入框中输入任务内容，选择分类，点击"+"按钮或按Enter键添加
2. **管理任务**：点击复选框标记完成，点击"编辑"修改任务，点击"删除"移除任务
3. **过滤任务**：使用顶部标签切换查看全部、进行中或已完成的任务
4. **排序任务**：点击"新"/"旧"按钮切换时间排序方式
5. **数据管理**：使用"导出数据"保存任务，"导入数据"恢复任务，"导入样例"快速体验

## 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 注意事项

- 数据存储在浏览器本地，清除浏览器数据会导致任务丢失
- 建议定期使用"导出数据"功能备份任务
- 导入数据会覆盖现有任务，请谨慎操作
